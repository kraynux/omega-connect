**Omega-connect** คือตัวเชื่อมโยงของชุด `omega-`: ค้นหาแอปพลิเคชัน omega ที่ติดตั้งไว้ (omega-serv, omega-fire, omega-jail…) บนเครื่องนี้และบนเครื่องต่าง ๆ ในเครือข่ายของคุณ แสดงว่าอะไรเชื่อมโยงกันแล้วหรือยัง และจัดสิ่งที่ขาดหายให้กลับเข้าที่ — โดยแสดงสิ่งที่จะทำให้ดูก่อนเสมอ เมื่อเชื่อมโยงกันแล้ว แอปพลิเคชันจะค้นหากันเองได้โดยไม่ต้องเปิด omega-connect

## 1. วิสัยทัศน์และขอบเขต

แอปพลิเคชัน omega ถูกสร้างมาให้ทำงานร่วมกัน: ล็อกของ omega-serv ถูกอ่านโดย jail ของ omega-jail การแบนของ fail2ban ไปรวมอยู่ในบัญชีดำของ omega-serv และ omega-fire แสดงผลทั้งหมดนี้ แต่ไฟล์ต่าง ๆ ก็ต้องอยู่ในที่ที่ถูกต้อง มีสิทธิ์ที่ถูกต้อง และแต่ละแอปพลิเคชันต้องรู้ว่าแอปพลิเคชันอื่นอยู่ที่ไหน Omega-connect ดูแลเรื่องนี้ให้

### สิ่งที่ Omega-connect ทำ

- ค้นหาแอปพลิเคชัน omega บนเครื่องนี้ (โฟลเดอร์ส่วนตัว บริการ systemd, OpenRC หรือ runit, `/srv`, ทะเบียนอินสแตนซ์ของ omega-serv) และบนเครื่องอื่น ๆ ที่เข้าถึงผ่าน SSH ด้วยคีย์ของคุณ
- เก็บ **ทะเบียน** ของแอปพลิเคชันทั้งหมดบนทุกเครื่อง พร้อมเวอร์ชันและสถานะ
- ตรวจสอบ **การเชื่อมโยง** แต่ละรายการระหว่างแอปพลิเคชัน (ล็อกที่ jail อ่าน สะพานไปยังบัญชีดำ รายการที่ได้รับการปกป้อง ไฟล์ของ omega-jail ใน fail2ban บัตรประจำตัว พื้นที่ใช้ร่วมกัน) และบอกว่าอะไรมีปัญหา
- **ซิงค์**: สร้างบัตรประจำตัวที่ขาดหาย และเตรียม **พื้นที่ใช้ร่วมกัน** ที่แอปพลิเคชันใช้ค้นหากันเอง
- **ซ่อมแซม**: ให้แอปพลิเคชันที่เป็นเจ้าของไฟล์แก้ไขความคลาดเคลื่อนแต่ละจุดเอง omega-connect ไม่ทำแทนเด็ดขาด
- **อัปเดตหรือติดตั้งใหม่** แอปพลิเคชันที่เก่าเกินไปหรือติดตั้งไม่ถูกต้องบนเครื่องในเครือข่าย จาก Release บน GitHub ของแอปพลิเคชันนั้น (ตรวจค่าแฮชแล้ว)
- ดำเนินการกับเครื่องในเครือข่าย **จากเครื่องของคุณ**: ไม่ต้องพิมพ์อะไรที่เครื่องนั้น รหัสผ่านของเครื่องนั้นถูกถามเพียงครั้งเดียว โดยตัวเครื่องเอง
- สร้าง **รายงาน** ฉบับเต็ม (ข้อความ, JSON หรือหน้า HTML)

### สิ่งที่ Omega-connect ไม่ทำ

- ไม่แทนที่แอปพลิเคชันใด: fail2ban, omega-fire, omega-jail และ omega-serv ต่างยังคงทำหน้าที่ของตน
- ไม่เขียนทับไฟล์ของแอปพลิเคชันอื่นเด็ดขาด
- ไม่ติดตั้งสิ่งใดแบบถาวรบนเครื่องในเครือข่ายเพื่อสแกน และไม่ปล่อยให้มีบริการใดทำงานค้างไว้
- ไม่ถามรหัสผ่าน SSH เด็ดขาด และไม่เคยเห็นรหัสผ่านผู้ดูแลระบบของคุณ

## 2. การติดตั้ง

### สิ่งที่ต้องมี

- Linux, Python 3.10+
- สำหรับเครื่องในเครือข่าย: การเข้าถึง SSH ด้วยคีย์ และ Python 3.10+ บนเครื่องเหล่านั้น
- การเชื่อมต่ออินเทอร์เน็ตสำหรับ dependency (และสำหรับการอัปเดตจาก GitHub)

### การติดตั้ง

จากโฟลเดอร์ที่มีไฟล์เก็บถาวรอยู่:

```bash
tar -xzf omega-connect-0.1.0.tar.gz
cd omega-connect/
./install.sh
```

`install.sh`:

1. สร้างสภาพแวดล้อมเสมือน `.venv` (`.venv` ที่ไม่สมบูรณ์จะถูกย้ายไปเก็บไว้และสร้างใหม่)
2. ติดตั้ง omega-lib (ไลบรารีของชุด ซึ่งมีให้ในไฟล์เก็บถาวร) และ omega-connect
3. ทำให้ `omega-connect.sh` และ `install.sh` เรียกใช้งานได้
4. เพิ่ม alias `connect` ลงใน `~/.bashrc` และ `~/.zshrc` (ไม่ซ้ำ)

ไม่มีขั้นตอนใดต้องใช้สิทธิ์ผู้ดูแลระบบ

### การอัปเดต

จากโฟลเดอร์ **แม่** ที่มี `omega-connect/` อยู่ข้างใน (ห้ามทำจากภายใน `omega-connect/` เด็ดขาด: `tar` จะสร้างโฟลเดอร์ซ้อนกัน) ให้แตกไฟล์เก็บถาวรใหม่ทับลงไป แล้วรัน `install.sh` อีกครั้ง ไฟล์เก็บถาวรไม่มีข้อมูลในเครื่องใด ๆ (`var/`: ทะเบียนเครื่อง การตั้งค่า การส่งออก) จึงไม่มีสิ่งใดที่มีอยู่แล้วถูกเขียนทับ

```bash
tar -xzf omega-connect-<version>.tar.gz
cd omega-connect/
./install.sh
```

## 3. การใช้งาน

### โหมดโต้ตอบ (TUI)

```bash
./omega-connect.sh
```

หรือ `connect` ถ้าสร้าง alias ไว้แล้ว

เมนูหลักมีสองคอลัมน์:

| การจัดการ | การบำรุงรักษา |
|---|---|
| **ทะเบียน** — แอปพลิเคชันทั้งหมดบนทุกเครื่อง พร้อมเวอร์ชันและสถานะ | **ซ่อมแซม** — รายการทุกสิ่งที่มีปัญหา แล้วคุณเลือกเอง |
| **สแกน** — เครื่องนี้ และการเพิ่มเครื่องในเครือข่าย | **รายงาน** — เอกสารฉบับเต็ม สำหรับส่งออก |
| **การเชื่อมโยง** — สิ่งที่เชื่อมโยงแล้วหรือยัง พร้อมสถานะ | **การตั้งค่า** — ภาษา ธีม โฟลเดอร์ การล้าง |
| **การซิงค์** — เชื่อมโยงแอปพลิเคชัน บนทุกเครื่อง | **ช่วยเหลือ** — แต่ละเมนู หน้าที่ และรายละเอียด |
| **แดชบอร์ด** — ภาพรวม | **ออก** |

เส้นทางทั่วไป: **สแกน** (เครื่องนี้ แล้วตามด้วยเครื่องอื่น ๆ ของคุณ ซึ่งเสนอให้จากโปรไฟล์ Unison, `~/.ssh/config` และ `known_hosts` ของคุณ) → **ทะเบียน** (อัปเดตหรือติดตั้งใหม่ให้แอปพลิเคชันที่เก่า) → **การซิงค์** (ทำเครื่องหมาย แล้วซิงค์) → **การเชื่อมโยง** และ **แดชบอร์ด** เพื่อดูผลลัพธ์ → **ซ่อมแซม** ถ้ายังมีความคลาดเคลื่อนเหลืออยู่

ทุกการดำเนินการจะแสดงแผนของตนก่อน ไม่มีสิ่งใดเริ่มทำงานก่อนที่คุณจะยินยอม สำหรับเครื่องในเครือข่าย อินเทอร์เฟซจะหลีกทางให้เทอร์มินัลระหว่างการดำเนินการ: เครื่องนั้นจะถามรหัสผ่านของตนเองเพียงครั้งเดียว

### ภาษาของอินเทอร์เฟซ

อินเทอร์เฟซมีให้ใช้ใน 17 ภาษา: ฝรั่งเศส อังกฤษ สเปน โปรตุเกส (บราซิล) อิตาลี เยอรมัน ดัตช์ โปแลนด์ รัสเซีย จีนตัวย่อ เวียดนาม ไทย อินโดนีเซีย ญี่ปุ่น เกาหลี ฮินดี และอาหรับ เลือกได้ในการตั้งค่า (« Langue / Language » ซึ่งเป็นป้ายที่ไม่เคยแปล) และมีผลหลังจากรีสตาร์ทอินเทอร์เฟซ ตัวแปร `OMEGA_CONNECT_LANG` (เช่น `OMEGA_CONNECT_LANG=en ./omega-connect.sh`) บังคับใช้ภาษาหนึ่งตลอดเซสชัน บนคอนโซลข้อความของ Linux (TTY) ภาษาที่ไม่ได้ใช้อักษรละตินจะแสดงเป็นภาษาอังกฤษสำหรับเซสชันนั้น บรรทัดคำสั่งยังคงเป็นภาษาฝรั่งเศส

### ติดต่อและสนับสนุน

ความช่วยเหลือ (ปุ่ม `a`) มีหน้าจอ **ติดต่อและสนับสนุน**: *เลี้ยงกาแฟ* (หน้า PayPal ของนักพัฒนา), *ติดต่อฝ่ายสนับสนุน* (ที่อยู่อีเมลและแบบฟอร์มติดต่อของเว็บไซต์ แสดงให้เห็นตรง ๆ), *ลงทะเบียนเป็นผู้ใช้ (นิรนาม)* และ *ตรวจสอบการอัปเดต* การลงทะเบียนเป็นไปโดยสมัครใจ ปิดไว้เป็นค่าเริ่มต้น และส่งเพียงครั้งเดียว: ใช้เพื่อนับจำนวนผู้ใช้เท่านั้น และถ้าต้องการ ก็ระบุทวีปหรือประเทศของผู้ใช้ได้ (รายการที่กำหนดไว้แล้ว ไม่มีข้อความอิสระเด็ดขาด) สิ่งที่ส่งมีเพียงคีย์ที่สุ่มขึ้น ชื่อซอฟต์แวร์ (`omega-connect`) และเวอร์ชัน ไม่ส่งชื่อ ชื่อเครื่อง ที่อยู่ หรือการตั้งค่าใด ๆ เด็ดขาด ที่อยู่ IP ไม่ถูกบันทึกในการลงทะเบียน แต่เช่นเดียวกับการเข้าชมทุกครั้ง จะผ่านการตรวจสอบความปลอดภัยและล็อกของเซิร์ฟเวอร์ที่รับข้อมูล ถอนตัวได้ทุกเมื่อจากหน้าจอเดียวกัน การตรวจสอบการอัปเดตอ่านเพียงรายการเวอร์ชันที่เผยแพร่แล้ว และไม่ทำงานเองโดยไม่มีการคลิกเด็ดขาด

### โหมดเขียนสคริปต์ได้ (CLI)

คำสั่งใดก็ตามจะเปิดโหมดบรรทัดคำสั่ง:

```bash
# แอปพลิเคชันของเครื่องนี้ หรือของเครื่องในเครือข่าย (SSH ด้วยคีย์ของคุณ)
./omega-connect.sh scanner
./omega-connect.sh scanner moi@192.168.1.109

# เชื่อมโยงแอปพลิเคชันของเครื่องนี้ หรือของเครื่องในเครือข่าย
./omega-connect.sh synchroniser
./omega-connect.sh synchroniser --machine moi@192.168.1.109

# อัปเดตแอปพลิเคชันที่เก่าเกินไปของเครื่องในเครือข่าย (Release บน GitHub)
./omega-connect.sh mettre-a-jour --machine moi@192.168.1.109

# ซ่อมแซม: เครื่องนี้ หรือเครื่องในเครือข่าย
./omega-connect.sh reparer --machine moi@192.168.1.109

# สถานะของการเชื่อมโยงแต่ละรายการ และรายงานฉบับเต็ม
./omega-connect.sh verifier
./omega-connect.sh rapport --format html --enregistrer
```

`--simulation` แสดงแผนโดยไม่เริ่มทำสิ่งใด `--oui` เริ่มทำงานโดยไม่ถาม `--toutes-machines` ดำเนินการกับทุกเครื่องที่รู้จักต่อเนื่องกัน ทีละเครื่อง

## 4. เครื่องในเครือข่าย

- **การเชื่อมต่อ:** SSH ด้วยคีย์ของคุณเท่านั้น โดยเคารพ `~/.ssh/config` (alias, พอร์ต, ผู้ใช้) คีย์ที่ป้องกันด้วยวลีรหัสผ่านต้องโหลดไว้ใน SSH agent
- **การเชื่อมต่อครั้งแรก:** ลายนิ้วมือ (fingerprint) ของคีย์เครื่องจะแสดงก่อนสิ่งอื่นใด คีย์ที่เปลี่ยนไปจะถูกปฏิเสธ
- **การสแกน:** โปรแกรมถูกส่งเข้าไปในหน่วยความจำ แบบอ่านอย่างเดียว ไม่มีการติดตั้งหรือเขียนสิ่งใด และไม่มีการถามรหัสผ่านใด ๆ
- **การดำเนินการ** (ซิงค์ ซ่อมแซม อัปเดต): โฟลเดอร์ส่วนตัวชั่วคราวจะรับโปรแกรม และไฟล์เก็บถาวรถ้าจำเป็น แล้วจะถูกลบเมื่อเสร็จ รหัสผ่านผู้ดูแลระบบจะถูกถามโดยตัวเครื่องเองเพียงครั้งเดียว
- **ตัวตน:** เครื่องถูกจดจำจากค่าแฮชของตัวระบุระบบ ไม่ใช่จากที่อยู่: แม้เข้าถึงผ่านสองเครือข่าย ก็ยังนับเป็นเครื่องเดียว
- **การอัปเดต:** จาก Release บน GitHub ของแต่ละแอปพลิเคชัน ค่าแฮชของไฟล์เก็บถาวรถูกตรวจกับ `sha.txt` ก่อนส่งทุกครั้ง แล้วตรวจอีกครั้งบนเครื่องปลายทาง แต่ละแอปพลิเคชันถูกติดตั้งตามที่หัวข้อ «อัปเดต» ใน README ของแอปพลิเคชันนั้นระบุไว้

## 5. บัตรประจำตัวและพื้นที่ใช้ร่วมกัน

- **บัตรประจำตัว:** เมื่อติดตั้ง แอปพลิเคชัน omega แต่ละตัวจะเขียนไฟล์เล็ก ๆ ที่บอกว่าตนคือใคร (แอปพลิเคชัน เวอร์ชัน ตัวระบุ เครื่อง) ทุกคนอ่านได้ แต่บัญชีอื่นแก้ไขไม่ได้เด็ดขาด
- **พื้นที่ใช้ร่วมกัน:** `/var/lib/omega-synchro` สงวนไว้สำหรับกลุ่ม `omega-synchro` โดยมีเพียงผู้ดูแลระบบที่เขียนได้ Omega-connect คัดลอกบัตรประจำตัวและคำอธิบายของแต่ละแอปพลิเคชันไปไว้ที่นั่น แอปพลิเคชันจะค้นหากันเองได้ที่นั่น แม้ในขณะที่ไม่ได้เปิด omega-connect
- **ทะเบียนของพื้นที่ใช้ร่วมกัน:** ทุกสิ่งที่ omega-connect สร้างจะถูกบันทึกไว้ในนั้น การนำออกจะย้อนกลับเฉพาะสิ่งที่บันทึกไว้ และไฟล์ที่ไม่รู้จักจะไม่ถูกลบเด็ดขาด

## 6. ความปลอดภัย

- ไม่มีการยกระดับสิทธิ์ตอนเริ่มทำงาน: omega-connect ทำงานภายใต้บัญชีของคุณ sudo ถูกขอทีละการดำเนินการ โดยแสดงคำสั่งให้ดูก่อน
- การแก้ไขทำโดยแอปพลิเคชันที่เป็นเจ้าของไฟล์ (omega-jail สำหรับสิ่งที่ตนวางไว้ใน fail2ban, omega-serv สำหรับสิทธิ์ของ `var/` ของตน, แต่ละแอปพลิเคชันสำหรับบัตรประจำตัวของตน)
- ไม่มีการเปิดแอปพลิเคชันใดถ้าอาจถามรหัสผ่านโดยไม่มีเทอร์มินัล
- การค้นหาไม่ตามลิงก์สัญลักษณ์เด็ดขาด ไม่ข้ามไปยังระบบไฟล์อื่น และข้ามจุดเมานต์เครือข่าย
- การล้างโฟลเดอร์ส่งออกและโฟลเดอร์ภาพหน้าจอจะปฏิเสธโฟลเดอร์ระบบ โฟลเดอร์ส่วนตัว และโฟลเดอร์ของ omega-connect

## 7. การส่งออก

- **รายงาน**: สรุปของทุกเครื่อง รายการที่ชัดเจนของสิ่งที่ยังต้องทำ ทะเบียน เครื่องในเครือข่าย การเชื่อมโยงของแต่ละเครื่อง พื้นที่ใช้ร่วมกัน เป็นข้อความ, JSON หรือหน้า HTML (เลือกธีมได้)
- **ช่วยเหลือ**: ส่งออกเป็นหน้า HTML ได้
- **ภาพหน้าจอ**: `Ctrl+P` → «ภาพหน้าจอ» (SVG)
- โฟลเดอร์เริ่มต้น: `var/exports/` และ `var/screenshots/` ในโฟลเดอร์ของ omega-connect แก้ไขได้ในการตั้งค่า

## 8. สถาปัตยกรรม

Clean Architecture เช่นเดียวกับส่วนอื่นของชุด: `domain/` (กฎล้วน), `application/` (กรณีการใช้งาน), `ports/`, `infrastructure/` (SSH, ไฟล์, GitHub, คลิปบอร์ด), `interfaces/` (บรรทัดคำสั่งและอินเทอร์เฟซ Textual), `app/` (การประกอบ) dependency ชี้เข้าด้านในเสมอ และตรวจสอบโดย `import-linter` สัญญาที่ใช้ร่วมกันระหว่างแอปพลิเคชัน (บัตรประจำตัว คำอธิบาย พื้นที่ใช้ร่วมกัน) อยู่ใน `omega-lib`

## 9. การทดสอบ

```bash
source .venv/bin/activate
lint-imports        # ตรวจสอบกฎของ dependency
pytest -q
ruff check src tests
mypy src
```
